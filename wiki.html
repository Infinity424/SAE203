Architecture du projet

template pour raphael (en charge de l'Architecture du site) 


    /                          ← Racine du site
    ├── accueil.php            ← Page d'accueil (stats)
    ├── connexion.php          ← Formulaire de connexion
    ├── connexion_traitement.php ← Traitement POST connexion
    ├── deconnexion.php        ← Destruction de session + redirect
    ├── inscription.php        ← Création de compte
    ├── administration.php     ← Gestion des utilisateurs (admin) sinon retour a l'accueil
    ├── profil.php             ← Édition du profil utilisateur
    ├── visualiser.php         ← Liste brute de toutes les annonces
    ├── proposer.php           ← Formulaire d'ajout d'annonce
    ├── modifier.php           ← Modification / suppression d'annonces
    ├── rechercher.php         ← Recherche filtrée + inscription
    ├── calendar.php           ← Calendrier des trajets de l'utilisateur
    ├── wiki.php               ← Cette page
    │
    ├── /admin/
    │   ├── view_utilsateurs.php  ← Dump brut des utilisateurs JSON
    │   └── view_annonces.php     ← Dump brut des annonces JSON
    │
    ├── /data/
    │   ├── r209-tp_utilisateurs.json
    │   └── r209-tp_annonces.json
    │
    ├── /images/               ← Photos de profil (pseudo.ext)
    │
    └── /scripts/
        ├── fonctions.php      ← Toutes les fonctions PHP communes
        └── update-annonce.js  ← Script JS (prévu pour Fetch API)
