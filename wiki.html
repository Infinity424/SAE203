Accessible à tous les visiteurs sans connexion. Documente l'architecture, les fonctionnalités et les identifiants du projet.

1. Architecture du projet

Le projet est hébergé dans /var/www/html/SAE203/ (DocumentRoot Apache). Il est composé de deux parties : un intranet HTML/PHP et un site vitrine WordPress.

2. Description des fonctionnalités


2.1 Site vitrine — WordPress

Accessible à l'adresse : http://172.18.203.208/wordpress/

  • Site de présentation de l'entreprise
  • Contenu géré via l'interface d'administration WordPress
  • Thème personnalisable via /wp-content/themes/
  • Plugins installables via /wp-content/plugins/

2.2 Intranet — HTML/BOOTSTRAP/CSS/PHP

Accessible à l'adresse : http://172.18.203.208/intranet/connexion.php

  • Authentification : connexion par identifiant et mot de passe, session PHP, déconnexion
  • Inscription : création d'un compte utilisateur (écriture dans le fichier JSON)
  • Dashboard : page d'accueil avec statistiques (nombre d'utilisateurs, équipements)
  • Annuaires : consultation des clients, entreprises et partenaires
  • Finance : consultation des achats clients
  • Communication : module de communication interne
  • Offres : gestion et consultation des offres de l'entreprise
  • Profil : modification des informations personnelles du compte connecté
  • Administration : gestion des comptes utilisateurs, accessible uniquement aux administrateurs

2.3 Réécriture d'URL

Le serveur Apache est configuré avec une règle de réécriture d'URL. Une URL de la forme /valeur1/valeur2 est automatiquement réécrite en index.php?param1=valeur1&param2=valeur2. Cette règle est déclarée directement dans SAE203.conf (pas de fichier .htaccess).


2.4 Pages d'erreur personnalisées

Les erreurs HTTP (403, 404, 500, 503) affichent des pages HTML personnalisées déclarées dans la configuration Apache, sans rediriger l'URL.
